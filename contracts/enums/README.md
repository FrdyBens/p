- `PlaybackState`: `IDLE`, `BUFFERING`, `POP` (Playing), `PULS` (Paused), `PLOP` (Stopped), `COMPLETED`, `ERROR`
- `MediaType`: `VIDEO`, `AUDIO`, `SHORT_PULSE`, `LIVE_STREAM`, `PODCAST`
- `SourceProtocol`: `FILE`, `SMB`, `HTTP`, `HTTPS`, `HLS`, `WEBRTC`
- `DeviceType`: `PHONE`, `TABLET`, `TV`, `DESKTOP`, `CAR`, `EMBEDDED`
- `ServerType`: `PERSONAL_NAS`, `COMMUNITY`, `CLOUD_RELAY`
