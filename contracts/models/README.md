# Domain Models (`contracts/models/`)

Canonical definitions for:
- `Media.kt` / `Media.ts` — Decoupled logical media entity.
- `MediaSource.kt` / `MediaSource.ts` — Physical file or network stream host.
- `MediaVariant.kt` / `MediaVariant.ts` — Codec, resolution, and container variant.
- `User.kt` & `Persona.kt` — User identity and creator profile.
- `Device.kt` — Hardware node on LAN or paired remotely.
- `Server.kt` — Personal NAS or community streaming server.
- `PlaybackSession.kt` — Real-time playback session state.
- `Playlist.kt` & `PlaylistItem.kt` — User-curated and algorithmic packups.
- `HistoryEntry.kt` — Watch progress and completion flags.
- `Notification.kt` — Inbox alerts.
- `SearchQuery.kt` — Query and filter parameters.
